# 语义辅助激光定位与建图稳定性研究

智能感知课程项目。成员为程嘉俊、孟瀚珅。暂定验收日期为2026年12月8日。

## 研究目标
研究如何利用语义类别与连续观测可靠性，提高动态道路场景下定位和地图的稳定性。工程基础采用已有CENet与LeGO-LOAM语义SLAM复现工作。
