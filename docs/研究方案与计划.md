# 当前研究方案与计划

更新日期为2026年11月14日。暂定题目为《面向动态道路场景的语义辅助激光定位与建图稳定性研究》。

## 场景与研究问题
车辆经过人车混行道路，动态目标、遮挡和语义误分影响匹配约束。研究类别先验与跨帧稳定性如何影响定位误差、困难片段的跟踪表现和地图质量。

## 方法与实验
1. 核验现有代码中语义权重作用位置、残差类型和参考点云来源。
2. 完成原始SLAM、类别硬剔除、类别软加权三组对照。
3. 引入跨帧空间一致性修正权重，单独评估其贡献。语义一致性与空间稳定性分别记录。
4. 对地图更新进行独立消融，检查更新后的地图如何参与后续定位。

统一数据、参数选择流程、初始化、硬件和轨迹评价协议。定位采用轨迹误差、局部误差突增和失败情况。地图检查固定区域内的动态残留与结构保留，同时记录有效特征数和耗时。

历史PPT记载06、08序列APE轻微上升而RPE下降，来自仓库历史记录，尚需重新核验。正式实验需说明轨迹对齐方式，核查Sim(3)对激光里程计评价的影响。
